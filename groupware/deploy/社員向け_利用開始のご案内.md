# 【重要】社内グループウェアの利用開始について

〔11月4日（月）〕から、スケジュール・施設予約・申請（稟議等）は新しい社内グループウェアで行います。
〔11月30日〕までは、これまでのクロジカも見られますが、**新しい予定・申請はグループウェアに入れてください。**

## 開き方

- アドレス: **〔https://gw.example.co.jp/〕**
- 社外からは〔VPN に接続してから〕開いてください。
- ログインID と初期パスワードは、〔総務〕から個別にお渡しします。
- 初回ログイン時に新しいパスワード（10文字以上・英字と数字を含む）を設定してください。

## スマホでアプリのように使う（おすすめ）

ホーム画面にアイコンを置くと、アプリのように開けて、通知も受け取れます。

**iPhone**
1. **Safari** で上のアドレスを開く
2. 画面下の共有ボタン（□に↑）→「ホーム画面に追加」
3. ホーム画面の「グループウェア」アイコンから開いてログイン
4. 「個人設定 → 通知 → この端末で通知を受け取る」→「許可」

**Android**
1. Chrome で上のアドレスを開く
2. 右上の︙ →「ホーム画面に追加」（または「アプリをインストール」）
3. アイコンから開いてログイン →「個人設定 → 通知 → この端末で通知を受け取る」

**パソコン（Chrome・Edge）**
- ログイン後「個人設定 → 通知 → この端末で通知を受け取る」。ブラウザを閉じていても通知が届きます。

## できること

| メニュー | できること |
| --- | --- |
| スケジュール | 部署・全員の週間予定。空いている枠をクリックで登録。非公開の予定は他の人には「予定あり」と表示 |
| 施設予約 | 会議室・社用車の予約（同じ時間の重複予約はできません） |
| 日程調整 | 候補日を出して ○△× で回答 → 決まったら全員の予定に自動登録 |
| ワークフロー | 稟議・経費精算・休暇申請など。承認待ちが止まると承認者に自動でお知らせ |
| 掲示板 | 全社のお知らせ。誰が読んだかわかります |
| テンプレート集 | 収支シミュレーション・業務自動化ツールなどの社内テンプレート |
| ブログ | 現場の気づき・成功事例・地域情報の共有 |
| チャット | 1対1・グループのやりとり。写真や資料も送れます |
| ToDo | 自分のやること、他の人への依頼 |

## 通知について

チャットの新着、承認依頼、日程調整の回答依頼、ToDo の依頼などが届きます。
多すぎる場合は「個人設定 → 通知 → 受け取る通知の種類」で種類ごとに止められます。チャットはトークごとに 🔔 で止められます。

## 困ったときは

- パスワードを忘れた・ロックされた → 〔総務 内線○○〕へ（初期化します）
- 使い方の質問 → 〔社内チャットの「グループウェア質問」グループ〕へ
